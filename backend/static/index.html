两种真实工作模式

代码中的入口首先让用户选择“串口配置”或“局域网设备”，两个模式对应不同使用场景。

串口配置

自动列出本机串口，连接后读取设备配置，写入 WiFi、设备名称、网络模式、SIM PIN、转发通道，并显示底部实时串口日志。

局域网设备

设备已连接 WiFi 后，可通过 IP 管理配置、发送短信、执行 AT 指令、切换飞行模式、重启、恢复出厂和 OTA 升级。

局域网扫描

输入 CIDR 网段或自动识别，扫描带 LAN 密钥发现接口的 T3 节点，识别成功后加入设备列表。

短信与通话归档

Web 控制台把设备上报的短信和通话保存到本地数据库，并提供对话式查看与清理能力。

本地运行与 Windows 打包

项目后端使用 FastAPI、SQLite、PySerial，前端原项目使用 React + Vite；同时支持打包成无黑色控制台窗口的 Windows 单文件 T3Web.exe。

默认登录

默认账号为 admin / admin123，可通过环境变量覆盖管理账号。

本地服务

启动脚本会安装依赖、构建前端并启动本地 Web 服务，浏览器访问控制台。

单文件 EXE

双击 T3Web.exe 后自动选择端口、创建本地数据目录，并打开浏览器。
