# T3 短信转发器控制台（T3 Web）

T3 短信转发器控制台是一款运行在电脑（Windows / Linux / macOS）上的**本地管理控制台**，用于统一管理局域网内的 T3 短信转发设备，或经 USB 串口离线配置设备。它不依赖任何公网服务，所有数据保存在本机。

源码位于本项目：`backend/`（FastAPI + Uvicorn + SQLite + PySerial），`frontend/`（React 19 + Vite + TypeScript）。

---

## 功能概览

| 类别 | 能力 |
| --- | --- |
| 设备接入 | 两种模式：**局域网设备**（WiFi 已联网）与**串口**（USB 直连、首次开箱） |
| 设备管理 | 扫描发现、手动添加、刷新、删除局域网内的 T3 设备 |
| 设备控制 | 读取/接管设备配置、重启、恢复出厂、飞行模式、执行 AT 指令、OTA 检查与升级 |
| 短信能力 | 经设备发送短信；以对话形式查看短信/通话记录，支持搜索、删除、清空 |
| 配置管理 | 设备名称、WiFi、SIM 号码/PIN、网络模式、通话录音、转发通道、MQTT 上报 |
| 串口工作台 | 多串口连接、离线写入配置、配置复刻、导入导出、诊断、DTR/RTS、实时日志 |
| 打包分发 | 可生成单文件 `T3Web.exe`，免 Python/Node 环境即可使用 |

## 启动方式

### 单文件 EXE（推荐普通用户）

1. 双击 `dist\T3Web.exe`。
2. 自动弹出控制窗口，无需黑色命令行窗口。
3. 程序自动启动本地 Web 服务，并打开浏览器进入控制台。
4. 若该端口被占用，自动顺延选择可用端口（`8080 → 8081 → 8082 → 18080 → 28080`）。

> 数据目录：`T3Web.exe` 同级的 `data\`（数据库 `app.db`）。
> 运行日志：同级 `launcher.log`，启动异常时优先查看。

### 源码启动（开发者 / 需要自定义）

#### Windows

```powershell
.\start.bat
```

脚本会自动安装后端依赖、构建前端并启动服务。默认访问 `http://127.0.0.1:8081`。

#### Linux / macOS

```bash
./start.sh
```

默认访问 `http://127.0.0.1:8080`。

### 默认账号

| 用途 | 用户名 | 密码 |
| --- | --- | --- |
| 控制台登录 | `admin` | `admin123` |
| 设备（局域网）访问 | `admin` | `admin` |

> 首次使用请尽快修改登录密码与设备访问密码。

## 局域网模式

进入局域网模式后，顶部导航栏包含：**📱 设备管理** / **💬 短信记录**，右上角可切换白天/暗黑主题或退出登录。

### 设备列表

顶部统计条显示：设备总数、🟢在线数、卡槽总数、❌无卡数、🟡插卡数、✅已注册数。列表默认读取本地缓存**秒开显示**，刷新按钮并发探测所有设备在线状态与 SIM 注册信息。

搜索框支持按**编号 / 号码 / IP / 备注**过滤。

表格每列：设备编号、IP 地址、状态（🟢在线/⚫离线）、版本号、SIM 卡 1/2（号码+运营商+🟢已注册/❌未注册）、操作。

**操作按钮（图标+文字）：**

| 按钮 | 功能 |
| --- | --- |
| 🔄 刷新 | 重新读取该设备的在线状态与 SIM 信息 |
| ⚙️ 配置 | 打开接管面板，读写设备全部配置 |
| 💬 短信 | 弹出发送短信窗口 |
| 📋 记录 | 跳转到短信记录页查看该设备相关对话 |
| ⚡ 重启 | 向设备发送重启指令 |
| 🖥️ 后台 | 在新标签页打开设备自带 Web 后台（`http://<设备IP>`） |
| 🗑️ 删除 | 从列表中移除该设备（不影响设备本身） |

### 扫描发现

扫描功能集成在设备管理页面的工具栏中，包含网段前缀、起始/结束IP、设备密码输入框及操作按钮。

### 设备配置面板（接管）

点 **⚙️ 配置** 打开接管面板，保存按钮以醒目的置顶/置底栏展示，点击后一次性写回设备。

**配置分区：**

1. **设备身份**：设备名称、Web 用户/密码
2. **WiFi 热点接管**：SSID、密码（留空不修改）→ 保存 WiFi 并重连
3. **SIM 与网络**：SIM1/SIM2 号码、PIN 码（留空不修改）、网络模式（自动/WiFi only/4G only）
4. **通话/录音**：来电处理、挂断秒数、TTS 内容
5. **转发通道**（5 个通道）：名称、类型（15 种可选）、URL、参数、模板
6. **MQTT 上报**：开关、Broker 地址、端口、主题前缀、用户名、密码、心跳、状态间隔、Client ID
7. **AT/OTA/系统**：执行 AT 指令、OTA 检查与升级、恢复出厂、清空设备日志、重启

### 发送短信

点 **💬 短信**，填写目标号码、SIM 卡槽、短信内容，发送后记录到本机。

## 短信与通话记录

### 短信记录

以**对话**形式展示，类似聊天软件：全部/短信/通话 标签、按号码聚合、对话视图（接收/发出/来电气泡）、搜索过滤、清空。

### 通话记录

表格展示时间/号码/时长，支持刷新、删除、清空。

---

## 串口模式

左侧侧边栏显示 **T3短信转发器控制台**，用于设备经 USB 接入本机、尚未联网或需要离线写入配置的场景。

- **串口列表与连接**：列出本机串口，支持稳定连接/防复位/标准模式，波特率默认 115200
- **配置编辑**：设备名称、WiFi、网络模式、SIM PIN、转发通道，点 **写入当前串口** 下发
- **导入/导出/复刻**：JSON 导入导出，复刻到其他已连接串口
- **诊断与控制**：串口探测、DTR/RTS 控制、复位
- **实时日志**：底部全宽终端，WebSocket 实时流，自动降级为轮询

## 环境变量

| 变量 | 说明 | 默认值 |
| --- | --- | --- |
| `T3_UI_USER` | 控制台登录用户名 | `admin` |
| `T3_UI_PASS` | 控制台登录密码 | `admin123` |
| `T3_TOKEN_TTL` | 登录令牌有效期（秒） | `604800` |
| `T3_DEVICE_USER` | 设备访问用户名 | `admin` |
| `T3_DEVICE_PASS` | 设备访问密码 | `admin` |
| `T3_LAN_DEVICE_KEY` | LAN 发现密钥 | `T3-C3-LAN-KEY-2026` |
| `T3_MESSAGE_INGEST_TOKEN` | 旧 HTTP 上报 Token | 同 LAN 密钥 |
| `T3_HTTP_TIMEOUT` | 访问设备超时（秒） | `4.0` |
| `T3_SCAN_CONCURRENCY` | 局域网扫描并发数 | `64` |
| `T3_SCAN_TTL` | 扫描任务保留（秒） | `1800` |
| `T3_DATA_DIR` | 数据目录 | `data/` |
| `T3_DB` | SQLite 数据库路径 | `data/app.db` |
| `T3_STATIC_DIR` | 前端静态目录 | `backend/static/` |
| `T3_WEB_PORT` | EXE 启动首选端口 | `8080` |

## 常见问题

| 现象 | 排查建议 |
| --- | --- |
| 打开控制台提示无法访问 | 确认服务已启动；EXE 用户看 `launcher.log`，源码用户确认 `start.bat`/`start.sh` 无报错 |
| 扫描不到设备 | 确认设备已联网且与本机同网段；确认 LAN 发现密钥一致；用设备后台确认 LAN 发现已开启 |
| 设备显示离线 | 设备可能断电 / WiFi 断开；点"刷新"重试 |
| 配置面板保存按钮灰色 | 设备配置读取失败，先点"配置"确保读取成功；AT/OTA/重启仍可用 |
| 发送短信失败 | 确认 SIM 已注册、卡槽选择正确、设备 Web 账号密码正确 |
| 串口列表为空 | 确认 USB 已连接、驱动正常；确认已安装 pyserial |
| EXE 启动慢 | 首次需解包，等待数秒；如长时间无窗口，查看同级 `launcher.log` |
| 忘记控制台密码 | 通过环境变量 `T3_UI_USER` / `T3_UI_PASS` 重置 |

## 数据与安全

- 所有设备信息、短信/通话记录保存在本机 SQLite 数据库（`data/app.db`），不上传任何服务器。
- 设备访问密码默认 `admin/admin`，务必修改，避免局域网内未授权访问。
- 登录令牌存于浏览器本地，公用电脑使用后请退出。
- `dist/`、`build/`、`launcher.log` 为运行/构建产物，无需提交到版本库。
